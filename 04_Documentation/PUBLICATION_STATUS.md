# Publication and version history

Version 0.3.3 corrects handover when a teacher leaves out a previously planned draft. The GitHub and OpenAI editions have separate release schedules. [Codex package checks](../01_ChatGPT_Desktop_App/VALIDATION_REPORT.md)

On 27 November 2026, the OpenAI publisher dashboard showed **0.3.1 in review** and **0.2.5 publicly listed**. The public listing shows what a teacher gets by installing from the ChatGPT directory. A Codex user who also installs the GitHub edition can select its repository marketplace, `agentic-course-redesign-system`, to use the version distributed here. The repository's v0.2.5 tag preserves the preceding OpenAI package and policy documents. Historical validation reports describe their own versions. The GitHub release list records which source bundles have been distributed. [GitHub releases](https://github.com/gpochs/Agentic-Course-Redesign-System/releases)
