# Publication and version history

Version 0.3.3 corrects handover when a teacher leaves out a previously planned draft. The GitHub and OpenAI editions have separate release schedules. [Codex package checks](../01_ChatGPT_Desktop_App/VALIDATION_REPORT.md)

On 27 November 2026, OpenAI accepted **0.3.3 for review** after the publisher withdrew 0.3.1. All six skills passed the automated checks. The dashboard estimated review completion on 28 November 2026. On the day of submission, teachers installing from the ChatGPT directory still received **0.2.5**. [OpenAI directory listing](https://chatgpt.com/plugins/plugins_6a88cdd968088191b7a22c9e92cbb5ba)

Teachers can already install **0.3.3** from GitHub. In Codex, select the `agentic-course-redesign-system` repository marketplace to use that edition. [GitHub release 0.3.3](https://github.com/gpochs/Agentic-Course-Redesign-System/releases/tag/v0.3.3)

The 0.3.2 GitHub release introduced the nine teacher-facing steps, mixed sources and task-specific optional tools. Its versioned report records the checks on that release. [0.3.2 validation report](../05_Validation/VALIDATION_REPORT_v0.3.2.md)

The repository's v0.2.5 tag preserves the preceding OpenAI package and policy documents. Historical validation reports describe their own versions. The GitHub release list records which source bundles have been distributed. [GitHub releases](https://github.com/gpochs/Agentic-Course-Redesign-System/releases)

Installation and live tests depend on the host, account, workspace and available tools. The reusable editions start with the same lecturer decisions. Each host supplies its own file, browser and agent capabilities. [Platform compatibility](PLATFORM_COMPATIBILITY.md)
