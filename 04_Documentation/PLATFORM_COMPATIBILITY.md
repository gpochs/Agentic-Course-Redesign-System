# Platform compatibility

All editions use the same six skills and the same lecturer decisions. Host capabilities determine which models can be selected, whether a choice card is available, and which files or browser tabs can be opened. Choose the installed, subscription-backed model in the host. Each specialist receives a bounded brief. If the host runs only a single agent, identify sequential role reviews as such.

| Host | Where to use it | Material review |
| --- | --- | --- |
| ChatGPT web | Open the plugin directory in Chat or Work. Installation depends on the account and workspace. | Use an uploaded copy, an approved connection or a browser capability available to the web session. |
| ChatGPT desktop and Codex | Use the directory plugin, the repository marketplace or the project template. Astra and Sol can use the same workflow. | Open the exact cloud or LMS draft in the built-in browser. Inspect local Office files with their native applications when browser rendering omits evidence needed for review. |
| GitHub Copilot | Install the repository's Copilot plugin or use its project instructions. | Use the file, preview and browser tools exposed to the active session. |
| Claude Code | Use the Claude Code edition in the course workspace or the supported user installation. | Review the working copy in the host's preview or the authorised native application. |
| Google Antigravity | Use its edition and select the desired reasoning setting in the project's model picker. | Use the browser or preview available to the project. Record the specific draft inspected. |
| OpenCode | Use its user or project skills in a workspace dedicated to the course. | Use the tools actually connected to the workspace or open the exported file for review. |

In the tested Codex Plan mode, `request_user_input` supports two or three explicit choices and an automatic Other field. Other modes may expose a different question control. Use the ordinary-chat fallback if the live control cannot show the full decision.

If the host can show every option and accept a custom answer, use its choice card. Ask open questions in ordinary conversation. If a card would hide an option, list the complete set in chat. A model, browser tool, connector or user-wide installation supplies a capability. The lecturer chooses which sources and actions to authorise for each course.
