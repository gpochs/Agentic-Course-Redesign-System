# Privacy notice

## Repository and plugin

The Agentic Course Redesign System repository and skills-only plugin do not run
a hosted service, maintain a developer database, collect analytics or receive
course files. The package contains instructions, templates and local utility
scripts.

## Host platform and optional tools

When a lecturer uses the package, course content is processed by the selected
host application and any separately enabled connector according to that
provider's terms, privacy settings and workspace controls. Installing this
package does not itself authorise an upload, connector or external research
tool. OneDrive and similar folders are cloud-synchronised storage, not strictly
local storage.

## Lecturer responsibilities

Use one isolated project per course. Exclude student personal data,
submissions, grades, credentials and secrets by default. Before specialist
analysis, classify source material, confirm processing rights, separate
teacher-only assessment content, approve permitted tools and egress, and define
student-facing, lecturer-only and public-safe audiences.

The public repository contains only synthetic validation fixtures. Do not file
course content or personal data in GitHub issues.
