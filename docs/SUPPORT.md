# Support

For non-sensitive bugs or documentation improvements, open an issue in:

<https://github.com/gpochs/Agentic-Course-Redesign-System/issues>

Include the release version, operating system, host application and a minimal
synthetic reproduction. Never attach student data, real assessments, answer
keys, credentials, private course files or institutionally restricted content.
Do not include restricted paths, filenames or metadata in a public issue.

For a vulnerability, use the private route described in
[SECURITY.md](../SECURITY.md). Community support does not include reviewing an
institution's privacy, copyright or assessment policy.
