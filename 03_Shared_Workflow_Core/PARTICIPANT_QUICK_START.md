# Participant quick start

## Before opening the agentic workspace

1. Choose one course. Never combine unrelated courses in one project.
2. Create a short isolated folder on a personal computer or lecturer-controlled
   storage. A personal OneDrive is cloud-synchronised, not strictly local; use
   it for protected or assessment material only when authorised.
3. Gather current plans, slides, workbooks, learning objectives, assessments
   and keys. Gather relevant programme, learner, accessibility, grading,
   workload, permitted-tool and lecturer-style context.
4. Exclude student personal data, submissions, grades, credentials and secrets
   by default.
5. Select only the adapter for the platform you will use.

## In the project

1. Copy the adapter overlay and inactive course scaffold into the exact one-
   course folder using its preview-first instructions.
2. Put copied current files in `00_Source_Materials/` and context in
   `00_Context/`.
3. Start a new task and say: `Set up an agentic redesign project for this one course.`
4. Review the generated paths and confirm that no existing file will be
   overwritten.
5. Review source hashes, classifications, processing rights, teacher-only
   assessment boundaries, permitted roles/tools/egress and output audiences.
6. Approve Gate 0 only when those exact records are correct.

## What follows

The system moves from course brief to five-perspective preliminary scan, HITL
1, deeper research and reconciliation, HITL 2, blueprint and exact-target
approval, gated production, independent QA and HITL 3. The first run is manual.
Reusable-system changes, activation and an expiring schedule are later,
separate decisions.

Installation alone never reads course files, uploads content, activates a
runtime or registers a schedule.
