# Provenance

Version 0.2.2 is an inactive local candidate created under approved proposal
`ACR-SYS-20260820-004`. It adds Gate-0 umbrella routing, explicit durable
production/HITL-3/system-review sequencing, schema 7, and a preview-only schema
6-to-7 migration helper. It adds no runtime activation, schedule, connector,
authentication, permission or external egress. Publication, installation and
activation remain separate future decisions.

Version 0.2.0 preserved the course-independent workflow semantics of the
independently validated 0.1.0 candidate and added multi-platform packaging.

The frozen 0.1.0 evidence recorded before this repository was created:

- deterministic public source-tree digest: `C0AC3C5EE04499A776F85FC4F839144912D68682C94B70956EE7826CA7738C2E`;
- portable ZIP SHA-256: `6E4FF27139B96A2CF859935C8A27EE9B0E6B382CA0DC431D9F4BED055BCDA8B3`;
- package inventory SHA-256: `8A631F03465F89D4ECF95DDB349636793A9E0E5E5273FF4C22AD43BA81469AC3`; and
- portable-bundle validation SHA-256: `B39789EBD5BD852C18CE75D20BC3BF9D11CC98A8F632EB6B6A352B974B29FAFD`.

Those hashes prove the original starting candidate, not the v0.2.2 candidate.
The public v0.2.1 tag is the immediate repository baseline for this proposal.
Any future v0.2.2 release requires its own source inventory, archive hash,
adapter manifests and independent audit after all adapters are frozen.

The private pilot course that informed the workflow is intentionally absent.
No pilot file, learner data, assessment answer, course quotation, image or local
path is part of the public provenance record.
