# Provenance

Version 0.2.3 is the validated published release created under approved proposal
`ACR-SYS-20260821-005`. It adds pre-source Gate 0A processing eligibility,
schema 8 and preview-only schema-7-to-8 migration, terminal dormant course-run
closeout after the explicit improvement-review response, one informational
fresh-trigger guidance offer, and eligibility-bound fresh manual/scheduled
lineage. It also makes the school, vocational, professional and higher-
education adaptation boundary explicit. It adds no runtime activation,
schedule, connector, authentication, permission or external egress.

Version 0.2.2 was published under approved proposal `ACR-SYS-20260820-004`.
It adds Gate-0 umbrella routing, explicit durable
production/HITL-3/system-review sequencing, schema 7, and a preview-only schema
6-to-7 migration helper. The public package adds no schedule, connector,
authentication, permission or external egress. Its tag and release remain the
preserved rollback baseline for v0.2.3.

Version 0.2.0 preserved the course-independent workflow semantics of the
independently validated 0.1.0 candidate and added multi-platform packaging.

Those hashes prove the original starting candidate, not the v0.2.2 or v0.2.3 releases.
The published v0.2.2 tag is the immediate repository baseline for this proposal.
Any v0.2.3 release requires its own source inventory, archive hash,
adapter manifests and independent audit after all adapters are frozen.

The private pilot course that informed the workflow is intentionally absent.
No pilot file, learner data, assessment answer, course quotation, image or local
path is part of the public provenance record.
