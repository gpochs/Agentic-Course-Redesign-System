# Third-party notices

The helper scripts in this repository use only the Python 3 standard library.
The reusable adapter does not bundle course materials, third-party media,
student data, credentials, private keys, external model weights, active MCP
servers, active hooks, plugins, or connector entitlements.

This adapter's validation uses only the Python 3 standard library. Canonical
platform-neutral state, manifest, fingerprint, and preview-migration helpers
are mirrored into the project overlay; Codex-specific configuration is not.
Their passing result is static evidence rather than proof of Antigravity
runtime behaviour.

Any sources, images, texts or media added later to an individual course project
remain outside this reusable package and require their own rights, privacy,
security and attribution review.
