Store an approved inactive candidate here only after a successful course run,
the recorded mandatory read-only system-review offer and explicit response,
terminal `complete_dormant` closeout, a separately requested versioned
proposal, and the matching System Gate. The review covers workflow skills and
umbrella routing; plugin or platform adapter; AGENTS.md and agent
configurations; project template, state schema and migration; validators,
tests and QA; documentation; memory or other workflow-owned durable
instructions; schedule contracts; permissions, tools, external egress and
automatic behaviour; and compatibility, benefits, regressions, risks,
residual risks and rollback. Course acceptance or review consent alone
authorises no system file, install/publish/release, activation, schedule
registration or modification, immediate run, MCP/connector/authentication,
permission or external egress.

Silence waits and authorises nothing. The closeout's informational trigger
guidance creates no task, schedule, hook, or automation. Never resume the
dormant course run; only a fresh manual or separately authorised scheduled
trigger creates a new run and lineage bound to the current Gate-0A fingerprint.
