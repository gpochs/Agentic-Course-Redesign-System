# Third-party notices

The helper scripts in this repository use only the Python 3 standard library.
The reusable package does not bundle course materials, third-party media,
student data, credentials, private keys, external model weights, MCP servers or
connector entitlements.

Local release validation may invoke validator scripts supplied with an
installed Codex environment. Those validator scripts are not copied into or
redistributed by this repository. GitHub Actions may install PyYAML to satisfy
an official validator's runtime dependency; PyYAML is a CI dependency, not
bundled application code.

Any sources, images, texts or media added later to an individual course project
remain outside this reusable package and require their own rights, privacy,
security and attribution review.
