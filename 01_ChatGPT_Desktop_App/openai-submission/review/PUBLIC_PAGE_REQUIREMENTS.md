# Website, support, privacy, and terms page requirements

These are content requirements for the verified owner, not final legal text.
Each page must use a public HTTPS URL, identify the same publisher as the OpenAI
submission, and accurately describe the released version.

## Website

Include the plugin purpose, version, supported installation/publication status,
documentation link, publisher identity, support link, privacy link, terms link,
and an honest statement that installation does not activate a runtime or
schedule. Do not imply OpenAI endorsement.

## Support

Name a real support owner and process, supported contact channel, expected scope,
installation/update/removal guidance, how to report safety or security concerns,
and how users can obtain the exact plugin version. Do not publish a fabricated
email address or response-time promise.

## Privacy policy

Accurately cover at least:

- that this v0.2.1 candidate is skills-only and bundles no publisher-run MCP
  server, authentication, account, telemetry, or connector;
- what local or cloud-synchronised course files the host may access when the
  lecturer authorises them;
- the one-course, source-classification, teacher-only, and data-egress controls;
- that OneDrive storage is cloud-synchronised;
- that separately available host tools or external research services have
  their own data handling and require Gate 0 approval;
- retention, deletion, access, and contact information that the verified owner
  can actually honour; and
- applicable jurisdiction and effective/change dates chosen by the owner.

## Terms

Identify the verified contracting publisher, the plugin and version, licence
terms, permitted and prohibited use, user responsibility for rights/privacy/
institutional compliance, availability and support boundaries, disclaimers,
limitation terms, termination/removal, governing law, contact, and change date.
Have qualified counsel review the final page when appropriate.

## Cross-page release check

The four pages, manifest publisher fields, portal developer identity, GitHub
repository, release notes, and selected countries/regions must not conflict.
Revalidate the final plugin after adding the URLs to the public manifest.
