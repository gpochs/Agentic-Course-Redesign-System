# Release notes for v0.2.2

Version 0.2.2 is the current six-skill repository release. Its project template
is inactive by default, and repository publication is separate from host
installation, runtime activation, scheduling, and any universal Plugins
Directory submission.

The candidate makes the final workflow sequence explicit and resumable. Before
HITL 3, it requires a current-lineage production-completion declaration, a
separate approval of the exact Production Handoff target, and independent
verification of the saved handoff. After current-lineage HITL 3 final
acceptance, it records and asks the system-improvement review question exactly
once. A separate affirmative response authorises read-only system/run review
and one versioned proposal only.

State schema 7 adds durable HITL 3, review-offer and recovery records. A bundled
v6-to-v7 helper is preview-only and provides no apply or write mode. The update
also adds fail-closed validators and reviewer cases for skipped handoffs,
premature review, and attempts to treat the review response as file,
installation, publication, activation, or schedule authority.

The full system proposal applies the same semantics to the canonical shared
core and every documented platform adapter. The ChatGPT custom and public
runtime trees are byte-identical. `APPROVE SYSTEM FILES` remains a separate
current-lineage System Gate for exact candidate targets and still does not
install, publish, activate, register, or run anything.

This release adds no MCP server, connector, app, hook, credential,
authentication, telemetry, extra permission, runtime activation, or registered
schedule. It does not alter or republish the historical v0.2.1 release.
The historical v0.2.1 attached system-validation JSON describes the earlier
v0.2.0 archive and is not accepted as matching v0.2.1 or v0.2.2 evidence.
