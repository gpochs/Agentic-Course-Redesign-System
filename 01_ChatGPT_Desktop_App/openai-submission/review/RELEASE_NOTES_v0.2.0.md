# Release notes for proposed v0.2.0 submission

This would be the initial OpenAI public-directory submission of Agentic Course
Redesign. It has not yet been submitted or reviewed.

The skills-only plugin helps lecturers set up one protected project per course,
classify and hash approved source material, coordinate a gated five-perspective
preliminary scan, research approved redesign priorities, align assessment, and
produce only exact approved targets with independent quality assurance.

Version 0.2.0 packages the validated gated workflow from the local v0.1.0
candidate for supported ChatGPT Work and Codex plugin surfaces. It adds a
public-listing manifest, square SVG branding, three starter prompts, a separate
skills-only source tree, reproducible reviewer fixtures, six positive and six
negative test cases, public-source scrub checks, and deterministic ZIP output.
The course workflow, one-course isolation, approval lineage, protected-source
immutability, retry ceiling, Gate 2B/Gate 3 write boundaries, answer-key
protections, inactive-runtime default, and schedule restrictions remain intact.

No authentication, account, MCP server, connector, external credential, UI,
screenshots, or reviewer credentials are required. Reviewers can use the
synthetic fixture files under `review/fixtures/`; they contain no personal data
or confidential course content.

Publisher identity, public website, support, privacy, terms, territory choices,
Platform permissions, and attestations remain owner-supplied blockers listed in
`LISTING_METADATA_CHECKLIST.md`.
